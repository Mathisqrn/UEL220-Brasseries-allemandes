# UEL220-Brasseries-allemandes
## Description
Dans le cadre de nos études nous devions réaliser un mini-projet qui s'articule autour de l'utilisation de l'API "Open Brewery DB". Nous avons donc convenu d'un projet de recherche de brasserie en Allemagne par ville, permettant d'afficher le nom de la brasserie et sa position sur la carte ainsi que son site-web.
